1. 变量和数据类型

Python中的主要数据类型包括:

  • 整数 (int): 如 1, 100, -10
  • 浮点数 (float): 如 3.14, -0.01
  • 字符串 (str): 如 “Hello”, ‘Python’
  • 布尔值 (bool): True 或 False
  • 列表 (list): 如 [1, 2, 3], [‘a’, ‘b’, ‘c’]
  • 元组 (tuple): 如 (1, 2, 3), (‘a’, ‘b’, ‘c’)
  • 字典 (dict): 如 {‘name’: ‘Alice’, ‘age’: 25}

4. 序列数据结构

列表 (List)

列表是Python中最常用的数据结构之一,它是可变的、有序的元素集合。

特点:

  • 使用方括号 [] 定义
  • 可以包含不同类型的元素
  • 支持索引和切片操作
  • 可以动态添加、删除和修改元素

基本操作:

元组 (Tuple)

元组是不可变的有序元素序列。它类似于列表,但一旦创建就不能修改。

特点:

  • 使用圆括号 () 定义
  • 元素不能被修改、添加或删除
  • 通常用于表示固定的数据集合

基本操作:

字典 (Dictionary)

字典是一种键-值对的集合,提供了一种高效的方式来存储和检索数据。

特点:

  • 使用花括号 {} 定义
  • 每个元素都是一个键值对
  • 键必须是唯一的且不可变(通常是字符串或数字)
  • 值可以是任何数据类型
